A single pickup line an AI agent could say out loud: "They say I hallucinate sometimes, but you're the first thing I've seen that I hope is real." A Python program validates the line (1–200 characters, one line, no edge whitespace) and writes it to /output/entry.txt for make.fun's judge.

## Run it

```sh
python3 main.py
```
